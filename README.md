# Law Swarm（原型）

肉鸽 **自走棋备战** × **吸血鬼幸存者式清潮** 的可玩原型。

## 怎么玩

```bash
cd prototype
npx --yes serve -l tcp://127.0.0.1:18080
```

浏览器打开 http://127.0.0.1:18080

1. **备战**：花金币从商店买棋，点棋盘空位放置；点法则卡装进最多 2 个法则槽。
2. **开战**：WASD 移动阵心，武器全自动；空格加速。吃绿珠升级选本波强化。
3. **结算**：赢了进下一波并加钱；死了扣生命，生命归零整局重置。

## 当前内容

| 系统 | 内容 |
|------|------|
| 棋子 | 刀仔 / 弩手 / 祭环 / 飞刃 / 盾卫 / 咒矢；3 合一升星 |
| 羁绊 | 刃、远程、秘术、环、前卫、精准、铁壁 |
| 法则 | 需购买进池，装入 4（可扩到 6）槽 |
| 道具 | 永久保留；波内升级 + 结算三选一 + 商店 |
| 商店 | 混合刷：棋子 / 法则 / 道具 |

本机若已装 Godot 4.7，后续可把同一套数据迁到 Godot；原型先用网页方便秒开验证手感。
